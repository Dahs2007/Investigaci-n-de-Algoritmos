# Implementación del Algoritmo de Dijkstra en Rust

## Descripción

Este proyecto implementa el algoritmo de Dijkstra para encontrar la distancia mínima desde un nodo origen hacia todos los demás nodos de un grafo ponderado con pesos positivos.

## Requisitos

- Rust
- Cargo

## Compilación

cargo build

## Ejecución

cargo run

## Casos de prueba

1. Grafo simple.
2. Grafo con nodo aislado.
3. Grafo complejo.

## Casos borde

- Grafo vacío.
- Nodo inexistente.
- Nodo aislado.
